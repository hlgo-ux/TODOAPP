# My Tasks

브라우저에서 별도의 서버나 라이브러리 설치 없이 바로 실행할 수 있는 가볍고 직관적인 개인용 할 일 관리(Todo List) 웹 애플리케이션입니다.

---

## 1. 앱 소개
**My Tasks**는 일상과 업무의 할 일을 체계적으로 기록하고 관리할 수 있는 웹 앱입니다.  
브라우저의 `localStorage`를 활용하여 새로고침하거나 브라우저를 다시 열어도 등록한 데이터가 안전하게 유지됩니다.

---

## 2. 주요 기능
- **할 일 추가 및 자동 카테고리 분류**: 제목 입력 후 Enter 키 또는 추가 버튼으로 등록하며, 키워드(회의, 운동, 공부 등)에 따라 카테고리(업무/개인/공부)가 자동 지정됩니다.
- **인라인 수정**: 목록의 할 일 텍스트를 더블클릭하여 바로 수정할 수 있습니다 (Enter: 저장, ESC: 취소).
- **완료 체크 및 개별 삭제**: 체크박스로 완료 상태(취소선 및 흐림 처리)를 전환하고, 우측 '✕' 버튼으로 개별 삭제할 수 있습니다.
- **카테고리 필터 & 실시간 검색**: 전체/업무/개인/공부 필터 버튼과 실시간 검색창을 함께 사용하여 원하는 작업을 빠르게 찾을 수 있습니다.
- **진행률 시각화**: 전체 할 일 대비 완료 비율을 백분율 문구와 부드럽게 움직이는 애니메이션 바로 실시간 제공합니다.
- **완료 항목 일괄 삭제**: 완료된 할 일들을 확인 창을 거쳐 한 번에 정리할 수 있습니다.
- **반응형 2열 레이아웃**: 모바일 화면에서는 1열, 768px 이상의 데스크톱 화면에서는 2열(왼쪽: 입력/진행률, 오른쪽: 목록)로 쾌적하게 표시됩니다.

---

## 3. 실행 방법
1. 저장소(프로젝트 폴더)를 다운로드하거나 클론합니다.
2. `index.html` 파일을 더블클릭하거나 웹 브라우저(Chrome, Edge, Whale 등)로 드래그하여 실행합니다.
3. 별도의 웹 서버나 패키지 설치 없이 즉시 사용할 수 있습니다.

---

## 4. 파일 구조
```
Lap4/
├── index.html        # 화면 마크업 및 레이아웃 구조
├── style.css         # UI 디자인 및 반응형 미디어 쿼리 스타일
├── script.js         # 데이터 저장, 이벤트 제어, 키워드 자동 분류 스크립트
├── README.md         # 사용자 가이드 및 애플리케이션 설명서
├── PRD.md            # 제품 요구사항 정의서 (기획 문서)
├── GEMINI.md         # 프로젝트 규칙 및 단계별 진행 상황 기록
└── backup/           # 반응형 작업 전 원본 파일 백업 폴더
```
